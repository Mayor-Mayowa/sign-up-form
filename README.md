# Sign-up Form

A sign-up form built as a part of The odin Project's Intermediate HTML and CSS course.

## What i worked on
Getting the form stucture and styling right was the main challenge here.
Spent time making the validation states feel natural rather than jarring,
the red/green borders only shows after the user interacts with a field or tries to submit an empty field marked as required, not immediately on page load.

## Built with
- HTML relying on its client-side form validation.
- CSS
